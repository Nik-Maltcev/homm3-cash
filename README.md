# 💸 Денежный поток — веб-версия

Веб-адаптация классической настольной игры про финансы. Играйте за одним
устройством по очереди (1–6 игроков). Это оригинальная реализация: механика
вдохновлена классикой, но все тексты и цифры карт написаны с нуля.

## Как запустить

Просто откройте `index.html` двойным кликом — сервер не нужен, сборки нет,
зависимостей нет.

## Онлайн-режим 🌐

Каждый игрок заходит со своего устройства по **номеру комнаты** (4 цифры).
Соединение — P2P через WebRTC (библиотека PeerJS): **никаких регистраций,
ключей и базы данных не нужно** — сигналинг идёт через бесплатный облачный
сервер PeerJS.

**Как играть:**
1. Один игрок выбирает режим «🌐 Онлайн» → вводит имя → «Создать комнату» → видит номер.
2. Остальные вводят номер комнаты и своё имя → «Войти».
3. Хост нажимает «Начать игру» — все попадают за один стол со своих экранов.
4. Хостовой вкладке нужно оставаться открытой: она ведёт партию (движок крутится у хоста,
   остальные шлют решения — броски, покупки, торговлю акциями).
5. Если игрок случайно перезагрузил страницу — просто входит в ту же комнату под тем же
   именем: игра подхватит его обратно.

**Деплой на Vercel:**
1. Загрузите репозиторий на GitHub.
2. [vercel.com](https://vercel.com) → Add New Project → импортируйте репозиторий
   (framework preset: Other, сборка не нужна) → Deploy. Готово — ссылку можно
   рассылать друзьям.

Ограничение v1: если хост закроет вкладку, партия приостановится
(восстановление хоста — в планах). В редких «жёстких» мобильных сетях P2P
может не соединиться без TURN-сервера.

## Деплой

Версия полностью статическая — подходит любой хостинг:

- **GitHub Pages** — Settings → Pages → выбрать ветку. Игра заработает по адресу
  `https://логин.github.io/репозиторий/` (подпапка не мешает, все пути относительные).
- **Netlify / Vercel** — перетащить папку или подключить репозиторий, указаний сборки не нужно.
- **Свой сервер (VPS)** — отдать папку статикой через nginx, либо `npm start`
  (поднимет `serve.js` на порту 8765; порт меняется так: `node serve.js 8080`).

Для онлайн-мультиплеера (этап 2) понадобится постоянно работающий Node-процесс
с WebSocket — статический хостинг не подойдёт, нужен VPS или PaaS.

## Что реализовано

- **Крысиные бега** — кольцо из 24 клеток: зарплата, малые/большие сделки,
  дудады, рынок, сокращение, ребёнок, благотворительность.
- **12 профессий** с разными доходами, расходами и стартовыми кредитами.
- **Отчёт о доходах** у каждого игрока: зарплата, пассивный доход, расходы,
  активы, обязательства, котировки акций.
- **Акции**: когда выпадает карточка акции, все игроки по очереди могут
  купить/продать её по этой цене.
- **Банк**: кредиты шагом $1 000 под 10%/мес (лимит — 10 зарплат), досрочное
  погашение. При нехватке денег — экстренный кредит, вынужденная продажа
  акций и банкротство.
- **Выход из крысиных бегов**: пассивный доход ≥ расходов.
- **Скоростная трасса**: мечты, бизнес-возможности, удача. Побеждает тот, кто
  купил свою мечту или нарастил пассивный доход ещё на $50 000.
- **Две темы оформления** — выбор на стартовом экране (запоминается):
  «Классика» (тёмно-зелёное сукно) и «Heroes III» (пергамент, золото и дерево,
  клетки-тайлы как на карте приключений, диалоги-свитки). Правила одинаковы.

## Структура

```
index.html        — разметка
css/styles.css    — оформление
js/data.js        — профессии, клетки трасс, все колоды карт, мечты
js/engine.js      — движок: правила и состояние, БЕЗ обращения к DOM
js/ui.js          — интерфейс: рендеринг, модальные окна
```

Движок намеренно изолирован от интерфейса: он общается с UI через набор
хуков (`render`, `log`, `stockTrade`, `chooseAssetCard`, …). Это подготовка
к онлайн-режиму.

## Этап 2 — онлайн-мультиплеер (план)

1. **Сервер**: Node.js + WebSocket (`ws`), комнаты по 1–6 игроков.
2. Движок `engine.js` переезжает на сервер почти без изменений: клиент вместо
   вызова хуков получает события по сокету, модальные окна остаются в `ui.js`.
3. Сервер авторитетен: хранит состояние, валидирует действия, рассылает
   дельты; скрытых данных (порядок колод) у клиента нет.
4. Хот-сейтовые подсказки «передайте устройство» заменяются персональными
   запросами только тому игроку, которому адресовано решение.
